## Tech Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion · Supabase · Vercel

## Features

- Responsive design with dark and light modes.
- Hero section with avatar and floating tech icons.
- About and Experience sections.
- Interactive project gallery with category filters and detailed project modals.
- Grouped technical skills and certifications.
- Downloadable PDF resume.
- Contact section with Gmail and copy-email functionality.
- Live testimonials with manual approval through Supabase.
- Centralized portfolio content in `src/data/portfolio.ts`.
